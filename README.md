# LeetCode 艾宾浩斯复习助手 (Chrome Extension)

基于艾宾浩斯遗忘曲线（Ebbinghaus Forgetting Curve）与 **SM-2 间隔重复记忆算法** 的力扣刷题与复习管理 Chrome 扩展（Manifest V3）。

---

## ✨ 核心特性

- 🧠 **科学记忆模型**：基于经典 Anki / SuperMemo SM-2 算法，提供四档反馈机制（重来 / 困难 / 良好 / 简单），以动态记忆因子自动推算下一轮最佳复习日。
- 📊 **Popup 任务仪表盘**：
  - **今日待办**：优先展示超期题目与今日到期题目，卡片附带题号、难度、标签及核心解题思路。
  - **即时评定**：做完一键打卡，卡片动态平滑归档，顶部进度条与 Badge 角标实时刷新。
  - **题库档案**：支持按题号、算法标签与题目名称全局快速搜索过滤，方便随时查阅思路卡片。
  - **日历负荷与留存率**：可视化展现未来 7 天的每日复习量预测柱状图，以及题库记忆健康度统计。
- 🧩 **力扣页面原生悬浮胶囊**：
  - 访问 `leetcode.cn/problems/*` 或 `leetcode.com/problems/*` 时，右下角自动注入轻量悬浮挂件。
  - 自动识别当前题目信息，支持一键“纳入艾宾浩斯复习计划”。
  - 解题完成后就地一键评定打卡，零跳转无缝衔接。
- 🔒 **本地离线优先**：
  - 基于 `chrome.storage.local` 本地存储，数据完全属于用户，支持完整 JSON 导出与导入备份。

## 🚀 安装与使用指南 (Chrome 加载扩展)

本扩展基于现代前端工程化标准构建，构建产物位于 `dist/` 目录。

1. **构建扩展产物**（已预先构建完成）：
   ```bash
   npm run build
   ```
2. **在 Google Chrome 中加载**：
   - 打开 Chrome 浏览器，在地址栏输入：`chrome://extensions/`
   - 在右上角打开 **「开发者模式」(Developer mode)** 开关。
   - 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)** 按钮。
   - 选择当前项目的 **`dist`** 文件夹（即 `/home/algieba/projects/leetcode-tracker/dist`）。
3. **固定到浏览器工具栏**：
   - 点击 Chrome 右上角拼图图标（扩展程序），找到 **「LeetCode 艾宾浩斯复习助手」** 并点击图钉固定。
   - 图标角标将自动显示今日待复习题目数量！

## 📐 间隔重复算法参数对照 (SM-2)

| 选项 | 掌握度心智 | 算法行为 | 预期复习间隔 |
| :--- | :--- | :--- | :--- |
| **重来 (Again)** | 完全遗忘 / 卡壳看题解 | 轮次清零，衰减记忆因子 | **1 天后** 强制重练 |
| **困难 (Hard)** | 思考艰苦 / 勉强做出 | 间隔微增 $\times 1.2$，微调因子 | 约 **1.2 倍** 当前间隔 |
| **良好 (Good)** | 独立解答 / 常规 AC | 正常推进，乘记忆因子 | 第1轮 1d ➔ 第2轮 3d ➔ 乘因子倍增 |
| **简单 (Easy)** | 极速秒杀 / 触类旁通 | 加速推进，增加记忆因子 | 第1轮 2d ➔ 第2轮 6d ➔ 乘因子 $\times 1.3$ |
